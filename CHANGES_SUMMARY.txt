ARCHITECTURE CHANGE
================================================================================

BEFORE (Confused):
  Mac: Web UI + LangGraph + MCP Server (trying to call proxy)
  Windows: proxy.py with deprecated /query endpoint

AFTER (Clean):
  Mac: Web UI + LangGraph → calls Windows MCP server
  Windows: MCP Server → SQL Server (via VPN)

KEY INSIGHT:
  - MCP server REPLACES the proxy, doesn't use it
  - MCP server must run on Windows (has VPN access)
  - Mac services call Windows MCP server via HTTP

================================================================================
STARTUP PROCEDURE
================================================================================

PRODUCTION (Mac + Windows):
  1. Windows: cd vpn_config && start_mcp_server_windows.bat
  2. Mac: ./start_all_services_mac.sh
  3. Access: http://localhost:3000

DEVELOPMENT (Mac only):
  1. Update .env: MCP_SERVER_URL=http://localhost:8000, DB_DIALECT=postgres
  2. Start PostgreSQL: brew services start postgresql
  3. Start MCP locally: cd mcp_server && uvicorn server:app --reload
  4. Start Mac services: ./start_all_services_mac.sh
