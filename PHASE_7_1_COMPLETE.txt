🎯 WHAT WAS BUILT

The Problem:
  • LLM hallucinates column names (e.g., ORDER BY [Name] when Name doesn't exist)
  • Reactive validation catches errors AFTER generation
  • Fallback queries are slower and user experience suffers

The Solution:
  • Extract exact column names from Scout Catalog
  • Create structured JSON index of available columns
  • Pass index to LLM as CONSTRAINT (not just suggestion)
  • LLM constrained to use ONLY indexed columns
  • Result: Correct SQL on FIRST TRY

The Implementation:
  1. New MCP tool "get_column_index" on Windows/VPN host
  2. Returns structured mapping: {"dbo.Table": ["Col1", "Col2", ...]}
  3. LangGraph agent fetches this before SQL generation
  4. Prompt includes JSON index as explicit constraint
  5. LLM generates correct SQL immediately

BEFORE (Reactive):
  Text schema → LLM hallucination → Error → Fallback → Retry

AFTER (Preventive):
  JSON index → LLM constrained → Correct SQL → Success ✓

Impact: Immediate, first-try correctness instead of error recovery
