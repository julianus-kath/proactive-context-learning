  HALLUCINATION PREVENTION MECHANISM
═══════════════════════════════════════════════════════════════════════════════

  BEFORE (LLM Prompt):
  ┌────────────────────────────────────────────────────────────────────────┐
  │ System: Generate MSSQL query for the following user request.           │
  │                                                                        │
  │ Schema:                                                                │
  │ dbo.sales: order_id (int), customer_id (int), amount (decimal), ...   │
  │ dbo.products: product_id (int), name (varchar), price (decimal), ...  │
  │                                                                        │
  │ User: "Show top 5 products by sales amount"                           │
  │                                                                        │
  │ [LLM has HINTS but can GUESS]                                         │
  │ → "What if there's a total_amount field?"                             │
  │ → "Maybe product_name instead of name?"                               │
  │ → Result: SELECT TOP 5 product_name, total_amount FROM sales          │
  │          (Hallucinated! These columns don't exist)                    │
  └────────────────────────────────────────────────────────────────────────┘


  AFTER (LLM Prompt):
  ┌────────────────────────────────────────────────────────────────────────┐
  │ System: Generate MSSQL query for the following user request.           │
  │ IMPORTANT: ONLY use columns listed below. Do NOT use any other        │
  │ column names.                                                         │
  │                                                                        │
  │ Schema:                                                                │
  │ dbo.sales: order_id (int), customer_id (int), amount (decimal), ...   │
  │ dbo.products: product_id (int), name (varchar), price (decimal), ...  │
  │                                                                        │
  │ INDEXED COLUMNS (ONLY use these):                                     │
  │ dbo.sales: [order_id, customer_id, amount, order_date, ...]          │
  │ dbo.products: [product_id, name, price, category, ...]               │
  │                                                                        │
  │ User: "Show top 5 products by sales amount"                           │
  │                                                                        │
  │ [LLM has HARD CONSTRAINTS]                                            │
  │ → MUST use: order_id, customer_id, amount (not total_amount)         │
  │ → MUST use: product_id, name, price (not product_name)               │
  │ → Result: SELECT TOP 5 p.product_id, p.name, SUM(s.amount)           │
  │          (Correct! Uses only indexed columns)                         │
  └────────────────────────────────────────────────────────────────────────┘
