   - Benefit: 50% fewer disambiguation questions, better ranking

HOW TO USE
================================================================================

STEP 1: Call the new tools from your agents

  # Check view materialization
  response = await mcp.call("get_view_dependencies", {
      "view_name": "OrdersView"
  })
  
  # Get FK cardinality patterns
  response = await mcp.call("get_fk_cardinality", {
      "table_name": "OrderItems"
  })
  
  # Get domain clusters
  response = await mcp.call("get_domain_clusters")

STEP 2: Use the data in your agent logic

  if response["is_materialized"]:
      use_this_view = True  # Faster!
  
  for card in response["fk_cardinalities"]:
      if card["cardinality_type"] == "many-to-many":
          requires_dedup = True
