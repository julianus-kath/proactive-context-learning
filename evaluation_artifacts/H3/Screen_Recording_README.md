## What's in it

End-to-end footage of the H3 user study session: each participant working through the fixed task list of natural-language ERP queries against the production Sage deployment. Captures the chatbot UI, the participant's audible reasoning, and the agent's responses (SQL + answer + clarifications).

## Privacy controls applied

- Listed as **unlisted** on YouTube — accessible only to viewers with the direct link.
- Comments and embedding disabled.
- Original MOV preserved offline; YouTube copy can be made private or deleted post-grading.
- Participants gave written consent to the screen recording for evaluation purposes (see `Study_Outline/Consent Form_Signed.pdf`).

## Why not git / git-LFS

GitHub rejects files larger than 100 MB on push and recommends Git LFS for anything over 50 MB. At 7 GB, LFS storage costs and clone-time bandwidth would impose ~5–10 minutes of download on every examiner clone, with no playback benefit over unlisted streaming. The unlisted YouTube link delivers identical evidence with instant playback and zero git overhead.
