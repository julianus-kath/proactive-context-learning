# n8n Setup for Data Fusion Project

This guide explains how to set up n8n as an orchestration engine for the Data Fusion project, with a focus on connecting to the SQLite database containing synthetic data.

## Quick Start

1. **Generate the synthetic data and start n8n**:

   ```bash
   # Make the setup script executable
   chmod +x setup.sh
   
   # Run the setup script
   ./setup.sh
   
   # Start the Docker containers
   docker-compose up -d
   ```

2. **Access n8n**:
   - Open your browser and go to: http://localhost:5678
   - Create an account or log in

3. **Access the chatbot interface**:
   - Open your browser and go to: http://localhost:8080

## Detailed Setup

### 1. Understanding the Docker Compose Configuration

The `docker-compose.yml` file sets up:

- **n8n container**: The workflow automation platform
- **SQLite database**: Mounted from the host to the container
- **Chatbot UI**: A simple web server for the chatbot interface

Key configuration points:

```yaml
services:
  n8n:
    # ... other settings ...
    volumes:
      - ./n8n-data:/home/node/.n8n
      - ./synthetic_data.db:/home/node/synthetic_data.db  # SQLite database
      - ./:/home/node/project  # Project files
    command: >
      sh -lc "npm install -g n8n-nodes-sqlite3 && n8n start"
```

This configuration:
- Installs the SQLite3 node for n8n
- Mounts the SQLite database at `/home/node/synthetic_data.db` inside the container
- Mounts the entire project directory for access to Python scripts

### 2. Setting Up the SQLite Connection in n8n

1. In the n8n interface, create a new workflow
2. Add a new node and search for "SQLite"
3. Configure the SQLite node:
   - **Database Path**: `/home/node/synthetic_data.db`
   - **Mode**: Query

4. Test the connection with a simple query:
   ```sql
   SELECT name FROM sqlite_master WHERE type='table';
   ```

### 3. Creating a Webhook for the Chatbot

1. Add a "Webhook" node to your workflow
2. Configure it:
   - **Authentication**: None (for simplicity)
   - **HTTP Method**: POST
   - **Path**: webhook-test/37694deb-f310-4a1e-b198-aaff97f28e8d
   - **Response Mode**: Last Node

3. Add a "Function" node after the webhook to process the query:
   ```javascript
   // Get the query from the webhook
   const query = $input.body.query;
   
   // Return the query for further processing
   return {
     query: query
   };
   ```

### 4. Connecting to the Agent System

#### Option 1: Using Execute Command

1. Add an "Execute Command" node:
   - **Command**: python
   - **Arguments**: 
     ```
     /home/node/project/agent_system/run.py --query "{{$json.query}}"
     ```

2. Add a "Function" node to format the response:
   ```javascript
   // Format the response from the agent
   return {
     result: $input.body
   };
   ```

#### Option 2: Using HTTP Request (if you set up an API)

1. Add an "HTTP Request" node:
   - **URL**: http://host.docker.internal:5000/run-agent
   - **Method**: POST
   - **Body Content Type**: JSON
   - **Body**: 
     ```json
     {
       "query": "{{$json.query}}"
     }
     ```

### 5. Example Workflow: Database Query

Here's an example workflow that queries the database based on natural language input:

1. **Webhook** (receives query from chatbot)
2. **Function** (extracts query)
3. **Execute Command** (runs agent_system with query)
4. **SQLite** (executes SQL generated by agent)
5. **Function** (formats results)
6. **Respond to Webhook** (sends results back to chatbot)

## Troubleshooting

### Database Connection Issues

If n8n can't connect to the SQLite database:

1. Check that the database file exists:
   ```bash
   ls -la synthetic_data.db
   ```

2. Verify the file is mounted correctly in the container:
   ```bash
   docker-compose exec n8n ls -la /home/node/synthetic_data.db
   ```

3. Make sure the SQLite3 node is installed:
   ```bash
   docker-compose exec n8n npm list -g n8n-nodes-sqlite3
   ```

### Webhook Issues

If the chatbot can't connect to the webhook:

1. Check that the webhook URL is correct in the chatbot's script.js file
2. Verify the webhook is active in n8n (should show "active" in the webhook node)
3. Check for CORS issues in your browser's developer console

## Advanced Configuration

### Using Environment Variables

You can add environment variables to the `.env` file:

```
OPENAI_API_KEY=your_api_key_here
DB_TYPE=sqlite
DB_PATH=/home/node/synthetic_data.db
```

### Persistent Storage

The n8n data directory is mounted at `./n8n-data` to persist workflows and credentials between container restarts.

### Security Considerations

For production use:
- Enable authentication for n8n
- Use HTTPS for all connections
- Restrict access to the webhook with proper authentication
